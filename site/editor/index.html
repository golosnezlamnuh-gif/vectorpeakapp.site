Editor's desk

A workbench for the daily routine. It loads the real schedule, prepares the prompt for your AI assistant and checks the result before you publish. Everything runs in this browser. The only outside request is the schedule request to TVmaze. This page is hidden from search engines and is not linked from the site.

1. Load the facts

AI assistants make up details unless they are given real ones. Load the schedule first, and it goes into the prompt for you.

2. Get the prompt

Pick what you want to write. Fill in the boxes that appear, copy the prompt and paste it into your AI assistant.

3. Check the draft

Paste what the assistant wrote, after you have fact-checked it and edited it in your own voice. The checks are the same ones the site applies when it builds, so a green result means the text will be published.

4. Publish on GitHub

  1. Type your GitHub repository once, for example your-name/your-repo. This browser remembers it.
  2. Press the button to open GitHub's "new file" page. The file name is already filled in.
  3. Press "Copy text" above, paste into the big box on GitHub and press "Commit changes".
  4. Wait one or two minutes. The site rebuilds itself and the new text goes live.
